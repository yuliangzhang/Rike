03 / 写死的原则

不可协商的四条

来自周岭《认知觉醒》。这四条是产品约束，不是风格建议——违反其中任何一条，这个 app 会亲手把用户送回失控。

原则在 UI 上的具体含义为什么
用记录代替打卡不显示连续天数徽章、不显示未完成红点、无「打卡成功」动效打卡 → 认知闭合 → 为完成而完成 → 应付 → 放弃
设下限不设上限「下限」栏 placeholder 永远是「再累也做得到」；下限只能有一条下限太高就不是下限，是伪装成下限的上限
少即是多「最重要」硬性限一条，UI 不允许加第二条把约束写进数据模型，而不是靠自觉
中性不评价失控记录与未达成项无感叹号、无表情、无鼓励语愧疚是 N-1 触发器的燃料
